# Matter_Testing_Suite

Folders:
bin - contains the binaries needed to perform the commmissioning attack and bruteforce attack
config - contains the yaml files for stored  fingerprints and devices
kvs - contains all the kvs files generated from the Commissioning module
lib - contains the python libraries that make up the pen testing suite
log - contains stored Matter transactions recorded by the Passive Scan module
qr - QR images can be added here for the Commissioning Module to scan and utilise
scripts - Contains a batch script that was used for testing the fingerprinting module

File:
main_menu.py - root python file to execute as opposed to executing the modules individually
